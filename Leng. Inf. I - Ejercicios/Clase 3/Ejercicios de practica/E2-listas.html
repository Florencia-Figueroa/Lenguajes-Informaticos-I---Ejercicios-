Pasos para hacer un commit

  1. git add . = Agrega el contenido modificado al repo
  2. git commit -m "nombre del commit" = Le pone nombre al commit
  3. git push = Subi al repositorio lo agregado + el nombre que le pusimos al commit

Glosario de términos

HTML
Lenguaje de marcado utilizado para definir la estructura y el contenido de las páginas web mediante etiquetas.
XML
Lenguaje de marcado diseñado para almacenar y transportar datos de forma estructurada y legible tanto para humanos como para máquinas.
JSON
Formato ligero de intercambio de datos basado en texto, altamente utilizado para transmitir información entre un servidor y un cliente web.
DOM
Representación en forma de árbol de todos los elementos de un documento HTML que permite a los lenguajes de programación manipular su contenido y estructura.
